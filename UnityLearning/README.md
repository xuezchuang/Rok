# UnityLearning

This folder is for paired Unity + UE learning slices.

Current rule: every migration feature should be studied or prototyped on the Unity side and then rebuilt on the UE side, so the differences are visible instead of hidden inside a one-shot port.

Use one child folder or note per slice. Record:

- Unity source path or experiment path.
- UE target class, asset, script, or map.
- What Unity does.
- What UE does differently.
- Evidence used to accept the slice.

Do not store Unity generated caches here. Keep `Library/`, `Logs/`, `Temp/`, `Obj/`, and packaged builds out of this folder.
